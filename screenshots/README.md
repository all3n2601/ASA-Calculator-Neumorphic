## 📐 Screenshot Guidelines

### Dimensions
- **Recommended**: 1080 x 2400 pixels (9:19.5 aspect ratio)
- **Minimum**: 720 x 1600 pixels
- **Format**: PNG (preferred) or JPG

### Device
- Use a modern Android or iOS device/emulator
- Ensure clean status bar (or hide it)
- Use consistent device across all screenshots

### Content
- Show meaningful examples (not just "0" or empty screens)
- Use both light and dark modes where applicable
- Demonstrate key features clearly
- Ensure text is readable

### Quality
- High resolution (at least 72 DPI)
- No compression artifacts
- Clear and sharp images
- Good lighting/contrast

## 📱 How to Take Screenshots

### Android
1. Run the app on an emulator or device
2. Navigate to the desired screen
3. Press `Power + Volume Down` (device) or use emulator controls
4. Screenshots saved to `Pictures/Screenshots`

### iOS
1. Run the app on simulator or device
2. Navigate to the desired screen
3. Press `Cmd + S` (simulator) or `Power + Volume Up` (device)
4. Screenshots saved to Desktop (simulator) or Photos (device)

### Using Flutter DevTools
1. Run app with `flutter run`
2. Open DevTools
3. Use the screenshot feature in the Inspector tab
